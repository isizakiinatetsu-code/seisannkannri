# Notion 連携 設定手順

納入管理システムの内容を Notion に自動で書き込みます（システム → Notion の片方向）。
**システム側が正**です。Notion で予定の中身を書き換えても、次の同期でシステムの内容に戻ります。

## Notion 側のページ

「🏗️ 納入管理システム 連携」ページの中に 4 つのデータベースがあります（初期構築済み）。

| DB | 中身 | Notion で自由に編集してよい欄 |
|---|---|---|
| 物件 | 物件ごとの件数・揃う予定日。関連する予定・要対応・発注忘れ候補がまとめて見える | （なし） |
| 納入予定 | システムの予定そのもの（削除した予定は Notion でもゴミ箱へ） | （なし） |
| 要対応（納入遅れ） | 納入日を過ぎても未納入・一部納入の予定。納入済みになると区分が「解消」に変わる | 担当・対応済み・対応メモ |
| 発注忘れ候補 | 現寸チェックの「未手配」を物件ごとにまとめたもの | 担当・確認済み |

「システム内部用（編集しないでください）」と書かれた列（システムID・物件キー・システム更新）は触らないでください。同期の目印です。

## 反映のタイミング

| 方法 | 内容 |
|---|---|
| 即時 | システムで予定を登録・変更・削除した直後に、その1件を反映 |
| 手動 | 左サイドバーの「🗂️ Notion 同期」ボタン（編集権限のみ）。全件を点検して差分を反映 |
| 定期 | GitHub Actions で毎時5分に自動実行（下の手順4）。Vercel Cron でも毎朝6時に実行 |

※ スプレッドシート同期で取り込んだ予定や、日付が変わって「納入遅れ」になった予定は、手動か定期の同期で反映されます。

## 初回設定（約10分）

### 1. Notion のインテグレーション（連携用の鍵）を作る
1. https://www.notion.so/profile/integrations を開く
2. 「新しいインテグレーション」→ 名前「納入管理システム」、種類「内部」、ワークスペースを選んで保存
3. 機能（Capabilities）で「コンテンツを読み取る・更新する・挿入する」にチェック
4. 「内部インテグレーションシークレット」（`ntn_…` で始まる文字列）をコピー

### 2. 連携ページにインテグレーションを接続する
1. Notion で「🏗️ 納入管理システム 連携」ページを開く
2. 右上「•••」→「接続」→ 手順1で作った「納入管理システム」を追加
   （これで配下の4つのDBに書き込めるようになります）
3. みんなで見る場合は、このページをチームスペースへ移動するか共有してください

### 3. 納入管理システムに鍵を設定する
Vercel → プロジェクト → Settings → Environment Variables に追加し、再デプロイ：

| 名前 | 値 |
|---|---|
| `NOTION_TOKEN` | 手順1でコピーしたシークレット |
| `CRON_SECRET` | 定期実行用の合言葉。長いランダム文字列（例：パスワード生成で40文字） |

再デプロイ後、左サイドバーの **「🗂️ Notion 同期」** を1回押すと、既存の予定がすべて Notion に入ります
（件数が多いと数分かかります。途中で閉じても、もう一度押せば続きから進みます）。

### 4. 毎時の自動同期を有効にする（GitHub）
GitHub のリポジトリ → Settings → Secrets and variables → Actions →「New repository secret」で2つ登録：

| 名前 | 値 |
|---|---|
| `APP_URL` | `https://seisannkannri.vercel.app`（Docker 移行後はそのサーバーのURL） |
| `CRON_SECRET` | 手順3と同じ合言葉 |

登録後、Actions タブの「Notion 定期同期」→「Run workflow」で手動実行して、緑のチェックになれば完了です。

---

## Docker（自社サーバー）で動かす場合
`.env` に `NOTION_TOKEN` と `CRON_SECRET` を追加します。時間制限が無いので `NOTION_SYNC_BUDGET_MS=50000` にすると一度に多く進みます。
定期同期は、手順4の `APP_URL` をサーバーのURLに変えれば、そのまま GitHub Actions から動きます。

## うまくいかないとき
| 症状 | 原因と対処 |
|---|---|
| 「Notion 連携が未設定です」 | `NOTION_TOKEN` 未設定、または設定後に再デプロイしていない |
| 「Notion 404 … Could not find」 | 手順2の「接続」をしていない |
| 「Notion 401」 | トークンの貼り間違い |
| 定期同期が動かない | GitHub の `APP_URL` / `CRON_SECRET` と、Vercel の `CRON_SECRET` が一致しているか確認 |
