📁 Google Drive【納入管理】連携 設定手順

カレンダーで撮った伝票写真を、自動で Google Drive の【納入管理】フォルダに保存し、 Claude Cowork（claude.ai）から検索できるようにするための設定です。
所要時間：約10〜15分。3つのパートに分かれています。

パートやること場所
ADrive API を有効化Google Cloud Console
Bフォルダをサービスアカウントに共有Google Drive
CフォルダIDを Vercel に登録Vercel
💡 サービスアカウントのメールアドレスは、スプレッドシート連携で使ったものと同じです。 〇〇〇@〇〇〇.iam.gserviceaccount.com という形のアドレスで、パートBで使います。 分からなければ、パートA-3の画面で確認できます。

パートA：Drive API を有効化する

  1. ブラウザで https://console.cloud.google.com/ を開く。
    重要 画面上部のプロジェクト名が、スプレッドシート連携で使ったプロジェクトと同じか確認してください（違うと連携できません）。
    console.cloud.google.com
    Google Cloud  ｜  ▼ 納入管理プロジェクト（←ここがプロジェクト名）
  2. 左上の「≡（メニュー）」→「APIとサービス」→「ライブラリ」を開く。
  3. 検索ボックスに Google Drive API と入力して開き、有効にする を押す。

    すでに「APIを管理」と表示されていれば、有効化済みなのでそのままでOKです。

パートB：フォルダをサービスアカウントに共有する

⚠️ 最重要ポイント。ここを忘れると写真は保存されません。
サービスアカウント（ロボットのアカウント）に、フォルダへの「編集者」権限を渡します。
  1. Google Drive（https://drive.google.com/）を開き、【納入管理】フォルダを探す。
    まだ無ければ、新規 → フォルダ で「納入管理」という名前のフォルダを作る。
    💡 おすすめ：「共有ドライブ」の中に作ると確実です（左メニューの「共有ドライブ」）。 サービスアカウントはマイドライブに保存容量を持たないため、マイドライブ直下だと まれにエラーになることがあります。共有ドライブなら起きません。
  2. 【納入管理】フォルダを右クリック → 「共有」を選ぶ。
    Google Drive

    👤 共有

  3. 「ユーザーやグループを追加」の欄に、サービスアカウントのメールアドレスを貼り付ける。
    権限を 編集者 にして「送信」（または「完了」）を押す。
    「納入管理」を共有
    〇〇〇@〇〇〇.iam.gserviceaccount.com

    送信
    「通知が送れませんでした」のような警告が出ても問題ありません（相手はロボットなので通知不要）。そのまま進めてOKです。

パートC：フォルダIDを Vercel に登録する

  1. Drive で【納入管理】フォルダを開いた状態で、ブラウザのアドレスバーを見る。
    URLの末尾 folders/ の後ろの文字列が フォルダID です。これをコピー。
    https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz

    ↑ この黄色の部分がフォルダID
  2. Vercel（https://vercel.com/）で、このアプリのプロジェクトを開く。
    「Settings」→「Environment Variables」を開く。
  3. 新しい環境変数を追加する。
    Key（名前）Value（値）
    GOOGLE_DRIVE_FOLDER_IDパートC-1でコピーしたフォルダID

    Value
    1AbCdEfGhIjKlMnOpQrStUvWxYz


    Save
  4. 保存したら、再デプロイして反映する。
    「Deployments」タブ → 最新のデプロイの「⋯」→「Redeploy」。
    環境変数は再デプロイ後に有効になります。これを忘れると反映されません。

✅ 動作確認

  1. 納入管理システムを開き、編集権限でログイン。
  2. どれか1件の予定を開き、伝票写真を1枚追加する。
  3. Google Drive の【納入管理】フォルダを開く。
    納入日_物件名_品目_伝票ID_日時.jpg という名前の画像が増えていれば成功です 🎉
うまくいかないときは、以下を確認のうえご連絡ください：
・パートA：Drive API が「有効」になっているか
・パートB：フォルダの共有相手にサービスアカウントが「編集者」で入っているか
・パートC：環境変数名が GOOGLE_DRIVE_FOLDER_ID で間違いないか／再デプロイしたか

🔎 Claude Cowork から検索できるようにする

写真が Drive に入れば、claude.ai 側で Google Drive を連携するだけで検索できます。

  1. claude.ai を開き、左下の自分のアイコン →「設定」。
  2. 「コネクタ（Connectors）」→「Google Drive」を「接続」。
  3. 連携後、Claude に「納入管理フォルダの〇〇の伝票を見せて」のように頼めば、フォルダ内の画像を検索・参照できます。
