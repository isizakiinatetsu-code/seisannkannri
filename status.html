現状の問題点（共有運用できない理由）
🔴
SQLite はサーバーレスで動かない Vercel はファイルシステムへの書き込み不可。DB を Supabase (PostgreSQL) に移行が必要。
🔴
画像がサーバーレスで消える public/uploads/ はデプロイごとにリセット。Supabase Storage への移行が必要。
🔴
認証なし 誰でも全データの閲覧・編集・削除が可能。操作者の記録もない。
🟡
同時編集の競合制御なし updated_at カラムはあるが楽観ロック未使用。複数人が同時編集すると上書き発生のリスク。
🟡
OCR は未実装 OCRタブは「画像保存のみ」。納品書の自動読み取りは実装されていない。

次に必要なアクション
  • Supabase プロジェクトを作成する（ユーザー側の作業）
    supabase.com で無料プロジェクトを作成 → Project URL と anon key を取得
  • npm install を実行して依存パッケージをインストール
    node_modules が未インストール状態のため、開発開始前に必要
  • DB層の移行コードを実装（①〜③）
    lib/db.ts を Supabase SDK 版に置き換え、スキーマ SQL を Supabase で実行
  • Vercel にデプロイして動作確認
    環境変数（SUPABASE_URL / SUPABASE_ANON_KEY）を Vercel に設定してデプロイ
  • 認証・監査ログを追加（④〜⑥）
    基本的な共有動作が確認できてから実装する
